# Geometric Lib

## Общее описание решения

Библиотека `geometric_lib` - набор функций для вычисления площадей и периметров стандартных фигур. Реализованы функции для фигур: круг, прямоугольник, квадрат, треугольник

## Структура библиотеки:

```text
`geometric_lib`  
    ├── `circle.py`  
    ├── `rectangle.py`  
    ├── `square.py`  
    ├── `triangle.py`  
    └── `docs`  
         ├── `README.md`  
         └── `CHANGELOG.md`  
```

## Формулы для вычисления:

### Area
```
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = a * h / 2
```

### Perimeter
```
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c
```

## Описание файлов:

### circle.py

- `area(r)` — Вычисляет площадь круга по заданному радиусу r
    ```
    Возвращает площадь круга с заданным радиусом

        Параметры:
            r (float): значение радиуса
        
        Возвращаемое значение:
            (float): площадь круга
    ```

- `perimeter(r)` - Вычисляет периметр круга по заданному радиусу r
    ```
    Возвращает периметр круга с заданным радиусом

        Параметры:
            r (float): значение радиуса
        
        Возвращаемое значение:
            (float): периметр круга
    ```

- Примеры вызова:
    ```python
    print(area(3)) # 28.274333882308138
    print(perimeter(3)) # 18.84955592153876
    ```

### rectangle.py

- `area(a, b)` — Вычисляет площадь прямоугольника по заданным сторонам a и b
    ```
    Возвращает площадь прямоугольника с заданными сторонами

        Параметры:
            a (float): длина прямоугольника
            b (float): ширина прямоугольника
        
        Возвращаемое значение:
            (float): площадь прямоугольника
    ```
- `perimeter(a, b)` - Вычисляет периметр прямоугольника по заданным сторонам a и b
    ```
    Возвращает периметр прямоугольника с заданными сторонами

        Параметры:
            a (float): длина прямоугольника
            b (float): ширина прямоугольника
        
        Возвращаемое значение:
            (float): периметр прямоугольника
    ```

- Примеры вызова:
    ```python
    print(area(3, 4)) # 12
    print(perimeter(3, 4)) # 14
    ```

### square.py

    ```
    Возвращает площадь квадрата с заданными сторонами

        Параметры:
            a (float): длина стороны квадрата
        
        Возвращаемое значение:
            (float): площадь квадрата
    ```
- `perimeter(a)` - Вычисляет периметр квадрата по заданной стороне a
    ```
    Возвращает периметр квадрата с заданными сторонами

        Параметры:
            a (float): длина стороны квадрата
        
        Возвращаемое значение:
            (float): периметр квадрата
    ```

- Примеры вызова:

### triangle.py

- `area(a, h)` — Вычисляет площадь треугольника по заданной стороне a и высоте h
    ```
    Возвращает площадь треугольника с заданной стороной и высотой

        Параметры:
            a (float): длина стороны треугольника
            h (float): длина высоты к данной стороне
        
        Возвращаемое значение:
            (float): площадь треугольника
    ```
- `perimeter(a, b, c)` - Вычисляет периметр треугольника по заданным сторонам a, b и c
    ```
    Возвращает периметр треугольника с заданной стороной и высотой

        Параметры:
            a (float): длина первой стороны треугольника
            b (float): длина второй стороны треугольника
            c (float): длина третьей стороны треугольника
        
        Возвращаемое значение:
            (float): периметр треугольника
    ```

- Примеры вызова:
    ```python
    print(area(3, 4)) # 6
    print(perimeter(3, 4, 5)) # 12
    ```
